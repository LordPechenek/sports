# Обновление таблицы заказов

## Шаг 1: Создание таблицы order_items

Выполните этот SQL-запрос в phpMyAdmin или через консоль MySQL:

```bash
mysql -u ваш_пользователь -p ваша_база < sql/add_order_items.sql
```

Или скопируйте содержимое файла `sql/add_order_items.sql` и выполните в phpMyAdmin во вкладке "SQL".

## Что изменилось

### В админке (admin.php):
- ✅ Заказы теперь отображаются с подробным списком товаров
- ✅ Каждый товар показывает название, количество и сумму
- ✅ Добавлен блок с деталями заказа рядом с комментарием
- ✅ Статусы заказов цветовые (Новый, Обработан, Отправлен, Доставлен, Отменен)

### В личном кабинете пользователя (settings.php):
- ✅ История заказов показывает подробный состав каждого заказа
- ✅ Отображаются пожелания клиента
- ✅ Цветовые бейджи статусов

### При оформлении заказа (checkout.php):
- ✅ Товары сохраняются в таблицу `order_items`
- ✅ Связь заказа с конкретными товарами через product_id
- ✅ Сохраняется цена на момент покупки

## Структура таблицы order_items

| Поле | Тип | Описание |
|------|-----|----------|
| item_id | INT | ID элемента (автоинкремент) |
| order_id | INT | ID заказа (внешний ключ) |
| product_id | INT | ID товара |
| title | VARCHAR(255) | Название товара (копия на момент покупки) |
| price | DECIMAL(10,2) | Цена за единицу |
| quantity | INT | Количество |
| subtotal | DECIMAL(10,2) | Общая сумма позиции |
